# RAILWAY QUEST KANSAI

関西の鉄道を題材にしたブラウザゲーム。**京阪電鉄の全駅・駅順・位置関係を確実に覚える**ことを最優先に、すごろく対戦と関西鉄道クイズを組み合わせています。

```bash
npm install
npm run dev      # 開発サーバー
npm test         # データ整合性・問題生成・移動ロジックのテスト
npm run build    # 本番ビルド（dist/）
```

React + TypeScript + Vite。進捗は LocalStorage に保存されます。スマートフォン・PC 両対応です。

## ゲームモード

| モード | 内容 |
| --- | --- |
| MODE 1 京阪マスター | 駅名暗記／隣接駅当て（方面つき）／駅順並べ替え／路線別穴埋め／路線当て／路線図の位置当て／起点から何駅目／制限時間付き全駅テスト（入力・4択）／苦手駅の復習／習熟度で色分けした学習マップ |
| MODE 2 関西鉄道すごろく | 駅がマス。サイコロで進み、目的地に一番乗りを目指す。CPU 1〜3人（強さ3段階）、乗換駅で他社線へ乗換、青・赤・クイズ・カード・イベントマス、特急／快速特急／急行カード、駅長（最初に止まった駅）と決算収入、路線全駅制覇ボーナス |
| MODE 3 関西鉄道クイズ | 隣の駅／何線／乗換できる路線／何府県／目的地への行き方（乗換なし・1回乗換）／路線図の空欄。出題する会社を選べる |
| 路線図 | 関西全域の地理配置図（路線色分け・乗換表示・拡大縮小・駅検索）、京阪の模式路線図、路線別の駅一覧、駅をタップで詳細（隣駅・乗換・習熟度） |
| 成績・称号 | レベル・経験値、会社別の駅制覇率、路線別正答率、称号（「京阪マスター」など17種）、苦手駅ランキング、学習履歴、デイリーチャレンジ |

## 学習アルゴリズム（src/lib/mastery.ts）

- 1回正解しただけでは習得にならない。**3連続正解かつ累計4回正解で「習得」**、さらに**別の日にも正解すると「マスター」**
- 正解するたびに次の復習時刻を延ばす（5分→30分→1日→3日→7日→14日→30日）
- 間違えると連続正解数がリセットされ、すぐ再出題対象になる。21日以上正解していない駅は1段階下がる
- 出題は「未学習・苦手・復習時期」の駅ほど選ばれやすい重み付き抽選
- 京阪全89駅が「習得」以上で称号「京阪マスター」

## データ（src/data/）

| ファイル | 内容 |
| --- | --- |
| `railways/keihan.json` | 京阪全線（本線・鴨東線・中之島線・宇治線・交野線・京津線・石山坂本線・石清水八幡宮参道ケーブル）89駅。駅ナンバー・読み・府県 |
| `railways/hankyu.json` ほか | 阪急（京都・神戸・宝塚線）、阪神（本線・なんば線）、JR西日本（京都線・神戸線・環状線・東西線・学研都市線/奈良線/琵琶湖線/湖西線の一部区間）、Osaka Metro（御堂筋・谷町・堺筋・長堀鶴見緑地・中央線）、近鉄（京都線・奈良線）、南海（本線なんば〜泉佐野・空港線）、京都市営地下鉄（烏丸・東西線）、神戸市営地下鉄（西神・山手線・海岸線） |
| `transfers.json` | 乗換駅グループ（同一駅・改札外の徒歩連絡）。ここにない会社間の移動はすごろくでもできない |

駅の追加・修正は JSON を編集するだけで、隣接関係・乗換・地図・問題に自動反映されます。路線の `stations` は駅順、`loop: true` で環状線、`partial` は一部区間のみ収録の注記です。`npm test` で駅数・駅ナンバー連番・全駅の接続性などを検査します。

### データの注意点

- 駅名・駅順・駅ナンバーは制作時点の知識に基づいて収録しています（公式サイトとの機械的な照合はできていません）。特に**大津線の駅ナンバー（OT01〜OT21、OT31〜OT36）**は試験前に公式路線図で確認してください。
- 地図上の座標は概略です（位置関係の把握用）。
- 列車種別ごとの停車駅は収録していません（すごろくの特急カードは「サイコロが増える」ゲーム上の効果です）。
